Place Value Decimal Game

An interactive tactile math game focused on developing advanced number sense, decimal manipulation, and place value strategy.

Learning Objectives

  • Understand place value values from units to thousandths.
  • Strategize slot arrangement to optimize output decimal values.
  • Contrast and compare multi-digit decimal numbers.

Classroom Setup

  • Students: Pair students into dyads (Player 1 & Player 2).
  • Materials: 1 pair of scissors per dyad, pen/pencil.
  • Scoring: Complete rounds to score points.

Custom Rules & Classroom Matrix

Inject pedagogical variants to expand strategy dynamics during decimal matching.

Rule Change A: Smallest Wins

Instead of generating the largest possible decimal, players must place cards to construct the **smallest possible number** without placing 0 in the Units place if possible.

Rule Change B: Difference Scoring

The winner scores points equal to the absolute difference between the two decimals formed (e.g., if Player 1 forms $8.42$ and Player 2 forms $6.12$, Player 1 scores exactly $2.30$ points).
